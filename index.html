Vector Studio Help Guide

Search tools, workflows, shortcuts, and troubleshooting.

Getting started

Vector Studio opens with a New Document setup dialog. Choose the artboard name, preset or custom dimensions, background, transparency, and workspace theme, then create the document.

Typical workflow
  1. Create or open a document.
  2. Draw shapes, paths, or text.
  3. Use Selection or Vertex Selection to edit objects.
  4. Use Layers, Properties, Pathfinder, or Path Editing for more control.
  5. Save as a VGS project or export SVG, PNG, or Illustrator-compatible AI.

Navigation & canvas

Pan

With the Selection tool active, hold ⌘ Command and left-drag on macOS. On Windows/Linux, hold Ctrl and left-drag.

Zoom

Use the zoom controls at the bottom of the canvas, the View menu, or cursor-centred zoom where supported. Fit Artboard returns the canvas to a comfortable working view.

Pasteboard

The area outside the artboard remains editable, so objects can temporarily sit off-page like in a desktop vector editor.

Selection tools

Selection Tool V

Select, move, resize, rotate, group, align, distribute, duplicate, and delete whole objects. Shift-click adds or removes objects from a multi-selection.

Vertex Selection Tool A

Select individual anchors and Bézier handles. When an anchor is active, a floating quick menu provides Add, Delete, Smooth, Corner, Break Handles, Join Handles, and Scissors actions.

Quick context menu

The floating selection menu appears near active selections when it is not blocked by a dialog or overlay.

Shapes & N-gons

Primitive tools include Rectangle, Ellipse, Polygon (N-gon), Star, and Line.

Two-click creation

For most shape tools, the first click starts the shape, pointer movement previews it, and the second click commits it.

Polygon (N-gon)

The first click sets the polygon centre and opens the vertex-count dialog. Choose 3–64 vertices, confirm, then move the pointer to set the radius and click again.

Modifiers

Shift constrains applicable shape proportions. Alt creates applicable shapes from the centre.

Pen & path editing

Pen Tool P

Click to add straight anchors or drag while placing points to create Bézier handles. Press Enter to finish an open path.

Continue an open path

Select an open path, switch to Pen, and move near an endpoint. The endpoint preview indicates when the existing path can be continued.

Insert an intermediate anchor

With a path selected, hover a segment with the Pen tool. A preview marker appears near the nearest valid segment position. Clicking inserts an anchor, switches to Vertex Selection, and selects the new point.

Path Editing panel

Available commands include Add Point, Delete Point, Smooth, Corner, Break, Join, Join Paths, and Scissors.

Shape Builder & Pathfinder

Shape Builder Shift+M

Select at least two closed shapes, activate Shape Builder, then drag through regions to merge them. Hold Alt while using Shape Builder to subtract regions.

Pathfinder

The Pathfinder section provides Union, Subtract Front, Intersect, Exclude, and Divide operations for compatible vector shapes.

For predictable boolean results, convert complex live shapes to paths first when necessary.

Text & fonts

Text Tool T

Click for point text or drag to define an area text box. Double-click text with Selection to edit it directly on the canvas.

Typography

Adjust family, weight, size, line height, letter spacing, and alignment in Properties.

Google Fonts

Custom Google Font families can be added from the Text controls. Vector outline conversion uses outline-readable font data where available.

Convert to outlines

Convert text to vector outlines before workflows that require editable geometry instead of live text.

Color, gradients & strokes

Fill and stroke

New shapes default to no fill and a 1 px purple stroke. Fill, stroke, opacity, and advanced stroke settings are editable from the top controls and Properties.

Color picker & swatches

Use the custom color picker, saved swatches, or the eyedropper. Custom swatches are stored locally in the browser.

Gradients

Linear and radial gradients support editable color stops and geometry controls.

Stroke profiles

Stroke Profile presets add live variable-width rendering while keeping the original vector object editable. Available profiles include Uniform, tapered ends, one-sided tapers, Centre Bulge, Hourglass, and Brush.

Offset Path

Object → Offset Path creates inward or outward offsets for compatible paths.

Rulers, guides & snapping

Rulers can be toggled from View. Drag from a ruler to create a guide.

Guides can be shown, hidden, locked, cleared, and used as snapping targets. Guide positions snap to ruler increments unless Alt is held during guide placement.

Additional snapping options include grid, object edges, object centres, canvas edges, canvas centre, and rotation angles.

Layers, tabs & history

Layers

The Layers panel lists editable objects and groups. Layer visibility and locking affect interaction on the canvas.

Canvas tabs

Multiple documents can stay open at once. Use the + tab button for a new document, double-click tab names to rename, and use the tab context menu for additional actions.

History

The History panel retains up to 100 states per canvas tab. Click a history step to jump backward or forward to that state.

Themes & new documents

New Document setup lets you choose Dark, Light, or High Contrast with visual previews before creating the canvas.

You can also switch themes later from View. The selected application theme is saved locally and restored on future visits.

High Contrast uses stronger borders, bright focus indicators, yellow active states, and cyan guide accents.

Save & export

Save project

Save creates an editable VGS project that preserves document setup and vector objects.

SVG

SVG export preserves vector geometry and is the most direct format for web and vector interchange.

PNG

PNG export rasterises the chosen export area.

Illustrator-compatible AI

AI export produces a PDF-compatible vector .ai file. It preserves vector artwork but does not contain Illustrator-native private editing metadata or every live Illustrator feature.

Keyboard shortcuts

Copy / Paste: Ctrl/Cmd+C copies selected vector objects, Ctrl/Cmd+X cuts them, and Ctrl/Cmd+V pastes them with a small offset. Pasted objects preserve editable path data and appearance.

Troubleshooting

I cannot pan on a Mac

Use ⌘ Command + left-drag with Selection. Ctrl-click is commonly treated as a context click on macOS.

A boolean operation gives an unexpected result

Check that the selected objects are compatible closed vector shapes. Converting live shapes to paths can make results more predictable.

A Google Font will not convert to outlines

Live text can still display correctly even when an outline-readable font file cannot be resolved. Try a different font or a locally supported face.

A floating menu is missing

Selection quick menus intentionally hide while another dialog or blocking overlay is open.

Theme text is hard to read

Switch to another theme from View. High Contrast is designed for maximum separation between text, controls, and backgrounds.

Try a shorter search such as “pen”, “polygon”, “export”, “snap”, or “shortcut”.
